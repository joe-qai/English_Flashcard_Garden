# 英式音标规则

站点统一英式（`en-GB`）。音标只作为展示与校对依据，不参与朗读。

## 基本约定

- 用斜杠包裹：`/ˈæpl/`
- 重音 `ˈ`，次重音 `ˌ`（构建时会去掉次重音）
- 长音用 `ː`，不用 `:`
- 不使用美式 `ɹ`、`ɚ`、`ɝ`、`oʊ`

## 规范化顺序

`lib/normalize.mjs` 的 `normalizeIpa` 依次做：

1. 去掉首尾 `/`
2. `'` → `ˈ`，`"` → `ˌ`，`:` → `ː`
3. `ɹ` → `r`，`ɐ` → `ə`，`ɛ` → `e`，`ɚ` → `ə`，`ɝ` → `ɜː`，`oʊ` → `əʊ`
4. 去掉括号内容（如 `(r)`）与次重音
5. 多读音只取第一个（按 `,` / `;` 切）
6. 重音符若写在元音后，移到音节起首（`wˈɒn` → `ˈwɒn`）
7. 单音节去掉重音
8. 非双元音的 `a` → `æ`

## 音节计数

- 元音与双元音各算一个音节
- 词尾成音节 `/l/`、`/n/` 额外加一（`apple`、`table`、`station`）
- 长音符号 `ː` 后面的 `l` 不算成音节（`girl`、`small` 是单音节）

## 常见坑

| 现象 | 例子 | 处理 |
|---|---|---|
| 页面用 `'` 标重音 | `hə'ləʊ` | 转 `ˈ` |
| 页面用 `:` 标长音 | `bɜ:θdeɪ` | 转 `ː` |
| 页面用 `"` 标次重音 | `"aʊt` | 转 `ˌ` 后去掉 |
| 美式 `oʊ` | `gəʊ` 写成 `goʊ` | 转 `əʊ` |
| 括号可选项 | `ˈkʌlə(r)` | 去掉括号 |
| 多读音 | `ˈiːðə,ˈaɪðə` | 取第一个 |
| 重音写在元音后 | `wˈɒn` | 移到音节起首 |
| 单音节带重音 | `ˈkæt` | 去掉 `ˈ` |
| 多音节无重音 | `bənænə` | 补 `ˈ` |
| 未英式化的 `a` | `/bad/` | 改 `/bæd/` |

## 校对时的判定

- 缺音标：`ipa` 为空
- 未包裹：不以 `/` 开头或结尾
- 未规范化符号：含 `: ' "`
- 未英式化：含 `a` 且不是 `aɪ` / `aʊ`
- 多音节缺重音：去斜杠后不含 `ˈ`，且不是短语（不含空格）
- 单音节多标重音：去斜杠后含 `ˈ`，且不是短语

短语（含空格）不检查重音，因为功能词通常弱读，强行标重音反而错误。
