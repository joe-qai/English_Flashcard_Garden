# 校对清单

校对模式只输出报告，不改文件。每条问题包含：单词、单元、说明、证据、建议值。

## 1. 缺词 / 多词

**缺词**：教材源有，但整个词库都没有。

- 教材源按 `norm(en)` 去重，保留首次出现
- 已加入 `word-overrides.skip` 的词不算缺词
- 已归入其他册或拓展词的词不算缺词（词库里能搜到即可）

**多词**：本册词库有，但教材源没有。

- 常见原因：误收、教材改版后删除、词表页面缺单元
- 处理：核对教材原页；误收则从源移除，或改成拓展词

## 2. 单元归属 / 顺序

**单元归属**：同一单词在教材源与词库里的 `unit` 不同。

- 证据写成 `源 U3 → 词库 U4`

**顺序**：两侧共有词的相对顺序不一致。

- 只比较「源和本册词库都有的词」，缺词/多词不参与
- 报告第一个错位位置，附前后各一个共有词
- 词库应保留教材原始顺序，不按字母重排

## 3. 音标

| 问题 | 判定 |
|---|---|
| 缺音标 | `ipa` 为空 |
| 未包裹 | 不以 `/` 开头或结尾 |
| 未规范化 | 含 `: ' "` |
| 未英式化 | 含 `a` 且不是 `aɪ` / `aʊ` |
| 多音节缺重音 | 去斜杠后不含 `ˈ`，且不含空格 |
| 单音节多标重音 | 去斜杠后含 `ˈ`，且不含空格 |

建议值只做提示，不自动写入。音标最终以人工 override 为准。

## 4. 释义

| 问题 | 判定 |
|---|---|
| 空释义 | `zh` 为空 |
| 残留词性 | 出现 `n.` / `v.` / `adj.` 等 |
| 半角标点 | 含 `(` `)` `,` `;` `!` `?` |
| 省略号未统一 | 含 `...`，应为 `…` |
| 英文后缀重复 | 以 `（单词本身）` 结尾 |
| 释义重复 | 同一中文对应多个英文词 |

建议值来自 `tidyZh`，只展示不写回。

## 5. 图标

| 问题 | 判定 |
|---|---|
| 无图标也无色块 | `icon` 与 `swatch` 都为空 |
| 颜色词缺图标 | red/blue/green 等颜色词没有 `icon` |

功能词（am、too、the 等）保留首字母色块是预期行为，报告中会列出但不必逐条修。

## 处理原则

1. 报告只读，不改任何词库文件
2. 用户确认后，修正值写入 `data/word-overrides.json`，再重建
3. 批量删除或重命名必须逐条列出
4. 修完重跑校对，直到目标类别归零或剩余项都有明确理由
